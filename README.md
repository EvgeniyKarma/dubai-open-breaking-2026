# Dubai Open Breaking 2026

Desktop landing page for Dubai Open Breaking 2026, built with HTML, CSS and JavaScript.

## Local preview

Run `python3 -m http.server 5173` from the project directory and open http://localhost:5173.

The page uses Google Fonts (Poppins), a muted looping background video and an animated title. No build step is required.

## Competition pages

`/world-breaking-championships/` contains the responsive first screen (mobile uses fixed design typography and controls, a lower-left date and lower-right registration card; only the title and gaps reduce on narrow/short screens), scroll-triggered header, navigation drawer and a registration-price drawer with all three pricing phases. The Schedule section includes all three days on desktop/tablet and animated day tabs on mobile. The Judges gallery remains temporarily hidden; its scroll handlers are disabled while hidden. Hero and drawer navigation include Judges / Hosts / DJs and separate Crew Guests and Qualifiers Winners links for upcoming sections. Drawer labels stay on one line at 32px on desktop/tablet and 24px on mobile. Navigation links and Registration price use a whole-label 300ms hover roll with orange highlighting, while drawer entrance reveals remain per-letter. The preserved desktop Judges scene pins below the header while native page scrolling moves a finite nine-card track from the first centered judge to the ninth. The centered card expands automatically with synchronized spacing; each wheel or trackpad gesture advances one card. Arrow keys, Page Up/Down and Space also step through the gallery. It is hidden at tablet/mobile breakpoints until their designs are supplied. Competition format fills the visible viewport below the fixed header on desktop, tablet and mobile. Learn more opens a right-hand rules drawer (full-screen on mobile), with a fixed Close row and independently scrolling rules and tables. Prize money follows Competition format, with solo and crew payout tables and the same per-letter text reveals and line drawing as Schedule. Travel guide includes desktop, tablet and mobile Venue, Hotels, Transport and Food layouts. Hotels adds Ibis and Novotel at their Figma map coordinates, each with an independent details tooltip and an external map link. The venue stays visible in both tabs. Switching tabs restores the selected category’s starting view; the mobile Hotels view fits all three fixed-size markers, while Reset always restores the venue to the map center. The SVG can be dragged with a mouse or one finger, and touch devices support two-finger pinch zoom. Zoom buttons use 25 percentage-point steps, bounded by the initial maximum scale and a frame-covering minimum. Markers remain fixed in size and follow their map coordinates. Reset restores the initial scale and centered venue. Transport adds World Trade Centre, Emirates Towers and Max metro stations from the full-map design, each with a map link. Its mobile view frames the venue and World Trade Centre station. Transport Info auto-opens on the first category visit per page load; the Info button or an outside click closes it, and Info is mutually exclusive with location tooltips. Info scrolls independently when needed. Food adds seven cafes and restaurants from the design, with individual addresses and map links. Its mobile starting view frames all seven markers and the venue; tab changes replay the existing 300ms marker stagger, while Reset continues to center the venue. Venue details open on hover/focus or a touch tap and close outside or when dragging. Its map link shares the Menu button fill animation and mobile dimensions. The heading uses the shared per-letter reveal. Desktop/tablet use 24px side gutters and 24px beneath the tabs; mobile uses 16px side gutters for native page scrolling, with two tab rows and a 16px bottom inset. Tablet/mobile reserve a 96px strip below the map for native page scrolling. Other navigation targets await the remaining page content. The junior competition page is reserved for future work.
